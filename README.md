# GeoMaster

Lernspiel für die Geografieprüfung (7. Klasse, Schweiz): Kantone, Hauptorte,
Seen, Flüsse, Gebirge und Pässe der Schweiz sowie Länder, Hauptstädte,
Flaggen, Kennzeichen, Flüsse, Gebirge und Gipfel Europas — auf einer Karte,
in vier Schwierigkeitsstufen.

**Spielen:** https://nbergt.github.io/geomaster/

Läuft komplett im Browser, ohne Konto und ohne Server; der Lernfortschritt
bleibt auf dem eigenen Gerät (localStorage). Die Seite lässt sich auch
herunterladen und per Doppelklick auf `index.html` offline starten.
